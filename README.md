# soguk-zincir-uyum-raporu
# Soğuk zincir sıcaklık uyum raporu otomasyonu

Soğutmalı araçlardaki sıcaklık kayıt cihazlarından gelen CSV dosyalarını otomatik okuyan, sıcaklık ihlallerini bulan ve haftalık PDF uyum raporu üreten Python aracı.

- Python, pandas, SQL ve Power BI ile yazıldı
- 14 araçlık filonun tüm kayıtları tek seferde işlenir
- Bir müşterinin haftalık raporu 6 saatten 20 dakikaya indi
- İhlaller aynı gün bulunur

Staj sırasında tek başıma geliştirdim; kuralları operasyon müdürüyle birlikte belirledim.
